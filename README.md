# AI---Proctoring-System-For-Cheat-Prevention
Overview

The rapid growth of digital learning has increased the need for automated online examination monitoring systems. This project presents an AI-Based Student Examination Scanning System designed to detect suspicious activities during remote examinations using Artificial Intelligence and Computer Vision technologies.

The system monitors eye movements, facial orientation, and head movements in real time to identify potential cheating behaviors without continuous human supervision. It also includes facial recognition and sound monitoring features to improve examination security and maintain academic integrity.


Features**

Real-time eye tracking
Face detection and recognition
Head pose estimation
Suspicious activity detection
Alert generation system
Admin dashboard with cheating score
Automated logging and monitoring
